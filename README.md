# Sentiment-analysis# Sentiment Analysis

## Project Overview

Sentiment Analysis is a Natural Language Processing (NLP) technique used to identify and classify the emotional tone of a text.

This project analyzes the text provided by the user and classifies it into one of three sentiment categories:

* Positive
* Negative
* Neutral

The application provides a simple interface where users can enter text and receive the predicted sentiment.

## Features

* Text-based sentiment analysis
* Classification into Positive, Negative, and Neutral sentiments
* Simple and user-friendly interface
* Fast prediction
* Interactive web application
* Natural Language Processing based analysis

## Technologies Used

* Python

## How It Works

The application follows these steps:

```text
User enters text
        |
        v
Text Processing
        |
        v
Sentiment Analysis Model
        |
        v
Sentiment Prediction
        |
        v
Positive / Negative / Neutral
```
